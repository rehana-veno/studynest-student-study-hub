# StudyNest – Student Study Hub

StudyNest is a beginner-friendly web application designed to help students organize everyday school work in one place.

## Main features
- Homework and assignment tracker
- Subject, status, type, and priority filters
- Exam planner with countdowns
- Class timetable
- Quick revision notes
- Daily task goal
- Focus timer
- Progress and subject statistics
- Smart study plan based on task priority and deadlines
- Dark mode
- Local browser storage for demo data persistence

## Built with
HTML, CSS, JavaScript, and browser localStorage.

## AI use
AI tools (including ChatGPT) were used during development to brainstorm the project, structure features, write and improve code, debug issues, and explain implementation choices. The final project was reviewed and tested as a working student-study prototype.
